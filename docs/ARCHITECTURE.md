# 重构架构说明（第一轮验证）

## 当前目标

本提交只验证一个闭环：

`云门总图 → 弟子居 → 偏舍 → 返回弟子居 → 返回云门`

核心要求：进入下一层后，上一级地点完全退出视图，不采用“一级、二级、动作同时平铺”的菜单式展开。

## 目录职责

- `src/core/`：状态、路由、存档、时间、事件等跨系统核心能力。
- `src/world/`：地点树、NPC 日程、遭遇等世界数据。
- `src/ui/`：纯 UI 渲染与交互层。
- `assets/`：从原单文件 HTML 中逐步拆出的图片、音频与样式资源。
- `adult/`：只保留公开的接口说明；私人成人内容不进入仓库。

## 下一步（仅在闭环验证通过后）

1. 从原 HTML 迁移现有视觉框架和非成人素材。
2. 抽出时间系统（年 / 月 / 时辰）。
3. 迁移城镇、后山、演武场等多层地点。
4. 再迁移修炼、功法、战斗、NPC 日程和存档。
